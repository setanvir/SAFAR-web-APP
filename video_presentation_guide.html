3️⃣ 5 Software Design Patterns (Assignment 2)
2:30 – 4:30
🖥️ Screen Demo: Open DESIGN_PATTERNS_ASSIGNMENT(ID_232_134_001).md on VS Code and show the code files in backend/app/.
  • 1. Singleton Pattern backend/app/db/session.py Guarantees thread-safe connection pooling and prevents DB exhaustion.
  • 2. Factory Method Pattern backend/app/factories/package_factory.py Polymorphic creation between Tour Packages and Luxury Hotels without hardcoded if/else.
  • 3. Strategy Pattern backend/app/strategies/payment_strategy.py Interchangeable pricing algorithms (Credit Card +2.5%, Crypto -5%, Demo Wallet 0%).
  • 4. Observer Pattern backend/app/observers/booking_observer.py Event-driven decoupled system for DB audit logs, customer emails, and agency alerts.
  • 5. Facade Pattern backend/app/facades/travel_booking_facade.py Unified transactional pipeline orchestrating Factory, Strategy, DB commit, and Observers.

Spoken Script:

“For our Software Architecture requirements, we have implemented 5 Gang of Four design patterns:

First, the Singleton Pattern in our database manager uses double-checked locking to ensure only one connection pool instance is created across threads.

Second, the Factory Method decouples package instantiation so the system seamlessly supports polymorphic listing types.

Third, the Strategy Pattern handles dynamic pricing algorithms at runtime.

Fourth, the Observer Pattern broadcasts booking lifecycle events to audit logging, email notifications, and agency alerts.

Finally, the Facade Pattern provides a unified transactional entry point that coordinates all four subsystems in a single atomic transaction.”
